⚠️ Configuración requerida — Firebase no conectado
Para activar la sincronización en tiempo real entre todos los usuarios, necesitas agregar tus credenciales de Firebase.

Pasos:
1. Ve a console.firebase.google.com
2. Crea un proyecto → Agrega una app web
3. Copia el objeto firebaseConfig
4. Pégalo en el archivo firebase-config.js

Mientras tanto el sistema funciona en modo local (sin sincronización).
